Research ReAct 워크플로 — seed.yaml 정리 보고서

근거: .ouroboros/seed.yaml · 구현 참조: research_workflow.py · 생성일 기준 시드 메타데이터 timestamp

시드 목표는 LangGraph 기반 리서치·경량 팩트체크, Serper 실연동과 스텁 도구 혼합, 검증 단계 이후 조건부 분기(자동 재시도 → 사용자 게이트), 그리고 분기 사유를 UI에 한 줄로 노출하는 것입니다.

1. 사용할 외부 API (무료·저비용 위주 정리)

시드 제약상 OpenAI(gpt-5-mini)와 Serper(또는 동급 검색)는 필수 축에 가깝습니다. LLM·상용 검색은 “완전 무료 무제한”이 아닌 경우가 많아, 포트폴리오용으로 보조·대체로 쓸 수 있는 무료 API를 함께 적었습니다.

API / 서비스 역할 (시드 대응) 비용·특징 환경 변수
OpenAI API (Chat) ReAct 추론, 구조화된 검증(with_structured_output), 시드 고정 모델 gpt-5-mini 유료 사용량 과금. 시드에서 모델 변경 불가. OPENAI_API_KEY
Serper.dev (Google 검색) 실제 웹 검색 스니펫·URL 수집 — 시드 “최소 1개 실연동” 충족 Freemium 가입 시 무료 크레딧·제한적 무료 호출(정책은 사이트 기준). 프로덕션은 유료 플랜 검토. SERPER_API_KEY
Wikipedia MediaWiki API (선택) 개념·날짜 확인용 무료 백업 소스. API 키 없이 호출 가능(과도한 호출은 제한될 수 있음). 무료 공개 읽기 전용. —
Open-Meteo (선택) 날씨 등 수치·지역 정보 — 리서치 데모 확장용, 키 불필요. 무료 비상업·합리적 사용 조건(문서 확인). —
OpenAI Embeddings 시드상 “사용 시” text-embedding-3-small만 허용. 현재 구현은 임베딩 미사용. 유료 토큰 과금. OPENAI_API_KEY
정리: “무료 위주”로 쌓으려면 Wikipedia / Open-Meteo 같은 무키·저마찰 API를 도구로 추가하고, 비용이 나가는 축은 시드대로 OpenAI + Serper에 집중하는 구성이 현실적입니다. DuckDuckGo 등 비공식 스크래핑은 안정성·이용약관 이슈가 있어 보고서 추천 목록에서는 제외했습니다.

2. 실제 구현 Tool 리스트

아래는 research_workflow.py의 react_node에 바인딩된 도구입니다. Serper는 HTTP로 직접 호출하며, 나머지는 포트폴리오용 스텁입니다.

도구 이름 유형 설명
serper_web_search 실연동 Serper POST https://google.serper.dev/search — 질의에 대한 제목·URL·스니펫. 상태의 search_results에 정규화 저장.
stub_register_claim 스텁 주장을 “내부 체크리스트에 등록한 것처럼” 문자열만 반환 — 분기·ReAct 데모용.
stub_word_stats 스텁 텍스트 길이·단어 수 통계를 반환 — 도구 파이프라인 예시용.

그래프 수준에서의 “도구”가 아니라 LLM 이후 단계로, 검증 노드는 동일 OpenAI 모델에 EvalResult 스키마를 씌운 구조화 호출로 동작합니다(별칭 evaluate_node).

3. LangGraph 시각화

컴파일된 그래프는 MemorySaver 체크포인터를 사용합니다. 아래는 코드에 선언된 노드·조건부 엣지를 옮긴 논리 다이어그램입니다.

flowchart TD START([START]) --> Gate{gate} Gate -->|"user_decision == stop"| FS[finalize_stop] Gate -->|"awaiting_user + continue"| RP[resume_prep] Gate -->|그 외| R[react] RP --> R R --> E[evaluate] E --> RA{route_after_eval} RA -->|"finalize"| F[finalize] RA -->|"retry"| RT[retry_prep] RA -->|"human"| H[human_pause] RT --> R F --> END([END]) FS --> END H --> END

로컬에서 PNG/SVG로 뽑기: Python에서 build_research_graph().get_graph().draw_mermaid_png(...) 또는 print(build_research_graph().get_graph().draw_mermaid()) 로 Mermaid 문자열을 얻은 뒤 mermaid.live 등에 붙여넣을 수 있습니다. (환경에 Graphviz 등이 필요할 수 있습니다.)
